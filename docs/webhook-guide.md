# Webhook Integration Guide

AcquireMock dispatches signed HTTP `POST` webhooks when a payment settles (`status == "paid"`).

## Delivery Behavior & Headers

Every delivery request includes:

- `Content-Type: application/json`
- `X-Signature: <hex_hmac_sha256>`
- `X-Payment-ID: <payment_id>`

### Payload Schema

```json
{
  "amount": 25000,
  "card_mask": "**** **** **** 4444",
  "payment_id": "pay_1234567890",
  "reference": "ORDER-1001",
  "status": "paid",
  "timestamp": "2026-11-27T12:00:00"
}
```

- `amount` is an integer in minor currency units (for example, `25000` USD = `$250.00`).
- Redirects (`3xx`) are **rejected** and never followed.
- Delivery timeouts default to `WEBHOOK_TIMEOUT_SECONDS` (`10` seconds).

## Retry Policy & Background Worker

AcquireMock persists delivery state (`webhook_attempts`, `webhook_status`, `webhook_next_attempt_at`, `webhook_locked_until`) in the database and processes due retries via the dedicated worker (`python -m app.worker`):

- Maximum total attempts: `WEBHOOK_MAX_ATTEMPTS` (default: `5`).
- Exponential backoff schedule after failed attempts (`10 * 2^(attempt - 1)` seconds):
  - After attempt 1 failure -> retry in **10 seconds**
  - After attempt 2 failure -> retry in **20 seconds**
  - After attempt 3 failure -> retry in **40 seconds**
  - After attempt 4 failure -> retry in **80 seconds**
  - After attempt 5 failure -> `exhausted` (no further automatic retries)
- Manual retries via `POST /api/console/webhooks/{payment_id}/retry` require admin authentication + CSRF protection, are allowed only for `paid` payments whose webhook has not yet succeeded and whose attempts remain below `WEBHOOK_MAX_ATTEMPTS`, and are recorded in `webhook_logs` with `trigger: "manual"`.

## Signature Verification

AcquireMock signs the raw canonical JSON string generated by:

```python
json.dumps(payload, sort_keys=True, separators=(",", ":"))
```

Important canonicalization rules:
1. Keys are sorted **recursively** across all nested objects.
2. No extra whitespace after `:` or `,` (`separators=(",", ":")`).
3. Digest is lower-case hex HMAC-SHA256 using `WEBHOOK_SECRET`.
4. Always compare signatures using constant-time equality.

### Python

```python
import hmac
import hashlib
import json

def verify_acquiremock_signature(payload: dict, signature: str, secret: str) -> bool:
    canonical = json.dumps(payload, sort_keys=True, separators=(",", ":"))
    expected = hmac.new(
        secret.encode("utf-8"),
        canonical.encode("utf-8"),
        hashlib.sha256,
    ).hexdigest()
    return hmac.compare_digest(expected, signature)
```

### Node.js

```javascript
const crypto = require("crypto");

function sortKeysRecursively(value) {
  if (Array.isArray(value)) {
    return value.map(sortKeysRecursively);
  }
  if (value !== null && typeof value === "object") {
    return Object.keys(value)
      .sort()
      .reduce((acc, key) => {
        acc[key] = sortKeysRecursively(value[key]);
        return acc;
      }, {});
  }
  return value;
}

function verifyAcquireMockSignature(payload, signature, secret) {
  const canonical = JSON.stringify(sortKeysRecursively(payload));
  const expected = crypto
    .createHmac("sha256", secret)
    .update(canonical, "utf8")
    .digest("hex");

  const expectedBuf = Buffer.from(expected, "utf8");
  const actualBuf = Buffer.from(String(signature || ""), "utf8");
  if (expectedBuf.length !== actualBuf.length) {
    return false;
  }
  return crypto.timingSafeEqual(expectedBuf, actualBuf);
}
```

### PHP

```php
<?php

function sortKeysRecursively(mixed $value): mixed {
    if (!is_array($value)) {
        return $value;
    }
    if (!array_is_list($value)) {
        ksort($value, SORT_STRING);
    }
    foreach ($value as $k => $v) {
        $value[$k] = sortKeysRecursively($v);
    }
    return $value;
}

function verifyAcquireMockSignature(array $payload, string $signature, string $secret): bool {
    $sorted = sortKeysRecursively($payload);
    $canonical = json_encode($sorted, JSON_UNESCAPED_SLASHES);
    if ($canonical === false) {
        return false;
    }
    $expected = hash_hmac('sha256', $canonical, $secret);
    return hash_equals($expected, $signature);
}
```

### Ruby

```ruby
require "json"
require "openssl"

def sort_keys_recursively(value)
  case value
  when Hash
    value.keys.sort.each_with_object({}) do |key, out|
      out[key] = sort_keys_recursively(value[key])
    end
  when Array
    value.map { |item| sort_keys_recursively(item) }
  else
    value
  end
end

def verify_acquiremock_signature(payload, signature, secret)
  canonical = JSON.generate(sort_keys_recursively(payload))
  expected = OpenSSL::HMAC.hexdigest("SHA256", secret, canonical)
  return false unless signature.is_a?(String) && expected.bytesize == signature.bytesize

  OpenSSL::SecurityUtils.secure_compare(expected, signature)
end
```

## SSRF Security Guarantees

Before every outgoing webhook attempt, AcquireMock validates the URL and resolved IP addresses:

- Allows only `http://` and `https://` without embedded credentials (`user:pass@`).
- Resolves all `A` and `AAAA` DNS records and rejects private, loopback, link-local, CGNAT, multicast, reserved, and cloud metadata destinations unless `ALLOW_LOCAL_WEBHOOKS=true` in local development.
- Pins the HTTP connection directly to the validated IP address while preserving the `Host` header and TLS SNI/certificate validation to prevent DNS rebinding.
- Never follows HTTP redirects (`3xx`).
